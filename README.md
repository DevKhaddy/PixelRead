> Generate beautiful screenshots for your GitHub README in seconds.

PixelRead is a modern developer tool that transforms any website into polished, presentation-ready screenshots with customizable browser frames, device mockups, gradients, and export options.

Built for developers who want beautiful documentation without opening a design tool.

---

## ✨ Features

- 🌐 Capture screenshots from any public website
- 🖥️ Desktop and mobile previews
- 🌙 Light & Dark mode
- 🪟 Browser frames (Chrome, Safari, Edge)
- 🎨 Beautiful gradient backgrounds
- 📐 Adjustable padding and spacing
- 🔲 Rounded corners
- 🌫️ Shadow controls
- 📥 Download as PNG
- 📋 Copy Markdown image syntax
- ⚡ Fast, responsive interface
- 📱 Mobile-friendly

## 💡 Why I Built This

Most README screenshot tools are either too limited or require unnecessary editing afterward.

PixelRead was built to help developers create beautiful documentation with just a URL.

## ⚙️ Installation

Clone the repository.

```bash
git clone https://github.com/devKhaddy/pixelread.git
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npm run dev
```
